# ACCEPTANCE

What phpx owes, one box per claim, with the command that settles it. The claims come from [README.phpx.md](README.phpx.md); nothing here adds a goal that file does not name.

Two rules hold over every box. `atkins -f atkins.phpx.yml` passes before a box counts, because a reversal that breaks the runtime it reverses is no reversal. A box that names php behaviour ticks on the `--matrix` run and not on phpx alone: the expected output comes from running the source through `php` first, and output copied from phpx locks in its bugs.

`phpx` below is the binary `atkins -f atkins.phpx.yml build` installs. A tree with no GOBIN reads `bin/phpx` for the same command.

- [X] A follow from upstream lands without a hand on it. `PHPX_FORCE=1 atkins -f atkins.phpx.yml phpx:follow` takes upstream's tree, runs `migrations/`, and commits. The integration runs one way and no file has two authors. The run reports no conflict.

The semver tag builds when HEAD is that tag and at no other time, because this checkout inherited phpscript's tags.

- [X] `atkins -f atkins.phpx.yml` passes end to end. Eleven legs: the follow, the three lint gates, the go suite under the tag, the binary and the image, the database pair, the four fixture and lifecycle legs, and the closing fmt that leaves the tree clean.

## The five reversals

One folder per reversal under `phpx/testdata/`, documented in the README beside them. `phpx test ./phpx/testdata/...` runs the lot; each box names the folder that settles it on all three runtimes.

- [X] `global` binds a name in the global frame, and the `global` keyword reads it. `phpx test --matrix ./phpx/testdata/globals/...` passes the php column over nine php behaviours in one fixture, and `go test -tags phpx ./runner/ -run TestPhpxGlobal` covers the binding, the null a missing global arrives as, `unset`, and the local value the statement pushes out of reach. `go test ./runner/ -run TestPhpxGlobalBindsNothing` pins that an untagged build still answers upstream's no-op. The Flat stack column skips: the bytecode engine declines the program and the whole of it runs on the interpreter.
- [X] `extends` carries fields, methods, statics and constants to the child, `parent::` runs the parent's body with `$this` bound, `self::` in an inherited body resolves to the declaring class, an instance answers `instanceof` for every ancestor, and a catch clause naming an ancestor takes a thrown child. `phpx test --matrix ./phpx/testdata/inheritance/...`, plus `go test -tags phpx ./runner/ -run 'TestPhpxClass|TestPhpxAutoload|TestNoInheritanceAtRuntime'`, which stays green: the parent's members flatten into the child's `model.Class`, a parent no file declares resolves through the autoload queue, and no `Parent` field appears on the class. The fixture's Flat stack column skips because the engine declines a program that declares `extends`.
- [X] A trait's members land in every class that uses one. `phpx test --matrix ./phpx/testdata/traits/...` passes the php column over the members a trait contributes, a class method overriding one, a nested trait, a class property composing with an identical trait property, and the fatals php raises for a method collision, an incompatible property and a missing trait. `go test -tags phpx ./runner/ -run TestPhpxClassAppliesTraits` covers the merge and `TestPhpxClassRejectsTraitCollisions` the three messages. The fixture's Flat stack column skips because the engine declines a program that declares or uses a trait. Adaptations: `phpx test --matrix ./phpx/testdata/traits/...` also passes `adaptations.phpt` (`insteadof`, `as` alias, `as` visibility, in a class and in a nested trait), `go test -tags phpx ./runner/ -run TestPhpxAdaptTraits` covers the missing-method and missing-trait fatals. Limit: a trait declared in another included file is not seen.
- [X] `abstract class` refuses instantiation and leaves its abstract methods to the child. `phpx test --matrix ./phpx/testdata/abstract/...` passes the php column over a child that implements every method, an abstract class with no abstract method instantiated through a concrete child, and a trait's abstract method satisfied by the using class; six `error:` fixtures pin php's fatals: `Cannot instantiate abstract class A`, `Class B contains 1 abstract method and must therefore be declared abstract or implement the remaining methods (A::g)`, `Class C contains 1 abstract method ... (C::z)` for a class's own declaration, `Cannot call abstract method A::f()`, `Cannot make non abstract method P::f() abstract in class C`, and `Abstract function A::f() cannot be declared private`. `go test -tags phpx ./runner/ -run TestPhpxClass` covers the merge, the order the message lists methods in, and both refusals; the untagged build keeps upstream's empty body. The fixture's Flat stack column skips because the engine declines a program that declares an abstract class or method. Limits: a class's own abstract declaration is reported before a trait's, which is php's compile-time order but not a case the fixtures pin.
- [X] `stdClass` is the class a decoded JSON object names, at any depth, and a decoded instance is an ordinary property bag. `phpx test --matrix ./phpx/testdata/stdclass/...` passes the php column over the default shape, `$associative = false` and `null`, the array shape `true` asks for, a nested object, a list of objects, the document's order surviving a round trip, and the property bag's `instanceof`, `foreach`, `unset`, dynamic property and `(array)` cast. `go test -tags phpx ./stdlib/core/ -run TestPhpxJSONDecode` covers the same shape from the binding, and the untagged build keeps upstream's decoder. `stdlib/core/phpx_json.go` re-registers `json_decode` after `json.go`: the fork changes the PHP name alone, and the extension `JSON\Decoder` still answers arrays. Limits: invalid input raises where php answers null, `$depth` and `$flags` are ignored, and a script may still declare its own `stdClass` where php refuses the name (see the discoveries below).
- [X] Method visibility is enforced at a call. `phpx test --matrix ./phpx/testdata/classes/...` passes `method_visibility.phpt`: a private or protected instance method, static method or constructor called from outside its scope raises php's `Call to private method A::f() from global scope` (or `from scope B`), while `self`, `static`, `parent`, a closure inside the class, a subclass and another instance of the class all reach a protected or private member as php allows. `go test -tags phpx ./runner/ -run TestPhpxCheckVisible` covers the rule. Limits: `__call` does not replace a refused call, and a call through `call_user_func` or a first-class callable is not checked.
- [X] Property visibility is enforced at an access. `phpx test --matrix ./phpx/testdata/classes/...` passes `property_visibility.phpt`: a protected or private property read, written, compound-assigned or unset from outside its scope raises php's `Cannot access protected property A::$prot`, `isset` and `empty` answer false and true, `get_object_vars` and `foreach` list what the calling body may see, and a promoted private property follows the same rule. `go test -tags phpx ./runner/ -run TestPhpxPropVerdict` covers the table and `go test ./runner/expr -run TestQuietOnRefusal` the isset seam. Limits: a write to an ancestor's private property from a child shares the slot, `print_r`, `var_dump`, `json_encode` and `(array)` list every property, `__get` and `__set` are unsupported, and the engine declines a class with a non-public property, so such a program runs on the interpreter.

## OOP syntax

A gap in class syntax the framework snippets met on the way to a reversal. The gap is not one of the five, and it stays inside the OOP scope the standing prompt names.

- [X] A property type may open with `\`, as a parameter and a return type already could. `phpx test --matrix ./phpx/testdata/syntax/...` passes the php column over a `private \stdClass $value`, a nullable `?\ArrayObject`, a union `\DateTimeInterface|\stdClass` and a static `?\stdClass`. The class body parser read the backslash as a token it had no case for, and `parser/parser.go` accepts it where a property type starts. `Latte\Engine` writes `private \stdClass $providers;`.

## OOP semantics

A behaviour the five reversals leave open once they are combined. It is still OOP, and a framework snippet is where it shows.

- [X] A class meets `implements` with a method it inherits from a parent or takes from a trait, and an interface contributes its constants. `phpx test --matrix ./phpx/testdata/interfaces/...` passes the php column over a class satisfied by its parent's method, a class satisfied by a trait's, `Store::LIMIT` through the implementing class, `B::LIMIT` through the interface that extends the declarer, and a class constant of the same name winning. `go test -tags phpx ./runner/ -run 'TestPhpxContract|TestPhpxInterfaceConstants'` covers the seam, and `go test ./runner/ -run TestPhpxContractReadsOnlyTheClassUntagged` pins that the untagged build still reads the class's own declarations. `phpx lint` reads the same effective set, so `class B extends A implements I` is not reported missing, and it leaves a class whose parent the file does not declare to the runtime. The contract check now runs after the class table is built, so an autoloaded parent's methods count. The two upstream fixtures that pinned the old answers, `interface_constants_not_acquired.phpt` and `interface_constants_extends.phpt`, are dropped through `phpx/testdata/patches/REMOVED`. Limits: the bytecode engine declines a program that declares `extends` or a trait, so its column skips; the runtime must know the interface when the class hoists, so a class that includes the interface's file itself (the file hoists before its include statements run) or leaves the interface to the autoloader folds no constant (`go test -tags phpx ./runner/ -run TestPhpxInterfaceConstantsFromAnotherFile` covers the interface loaded first); a constant expression naming `self::` still does not resolve (see the discoveries below).
- [X] A constant expression and a static default may name `self::`, and an interface constant's expression too. `phpx test --matrix ./phpx/testdata/constants/...` passes the php column over `const B = self::A + 1`, `const C = K::B * 2`, `static $s = self::A` and `interface I { const Y = self::X * 3; }` read through `I` and through an implementing class. `helperClassConst` in `runner/runtime_eval.go` (overlaid whole, `phpx/testdata/patches/runner/runtime_eval.go`) evaluates the expression in the declaring class's scope and not in the scope that asked for it. Limit: a constant a child inherits evaluates `self::` as the child, since the flattened `model.Class.Consts` keeps no declaring class, and php answers the declaring class; it differs only where the child redeclares a constant the expression names.

- [X] `static::` binds late. `phpx test --matrix ./phpx/testdata/classes/...` passes the php column over `new static`, `static::class`, `static::CONST`, `static::method()` forwarded through `self::` and `static::`, `get_called_class()`, a closure built in a static method, a trait's `static` return, and `new self` naming the declaring class. `go test -tags phpx ./runner/ -run TestPhpxForwardedClass` covers the frame. Limit: a child that redeclares a static property shares storage with its parent; php keeps two.

- [X] A class extends a built-in throwable. `phpx test --matrix ./phpx/testdata/classes/...` passes the php column over `parent::__construct($m, $code, $previous)`, the inherited getters, a three-level chain, `instanceof` up the SPL hierarchy and `catch` ordering where a class extending `Error` is not an `Exception`. `getFile()`, `getLine()` and `getTrace()` answer empty values.

- [X] `__toString` supplies an object's string form in `echo`, the `(string)` cast, concatenation, `strval`, `sprintf`, `implode` and `str_replace`, own, inherited or from a trait. `phpx test --matrix ./phpx/testdata/classes/...` passes the php column over `tostring.phpt`.

- [X] `readonly` properties are set once, from inside the declaring class. `phpx test --matrix ./phpx/testdata/classes/...` passes `readonly.phpt` over a declared and a promoted property, a `readonly class`, a second write, a compound write, an `unset`, an indexed write, a child writing the parent's property and a first write from global scope. Go test: `TestPhpxReadonlyWrite`.
- [X] `Closure::bind` carries `$this` and the class scope, so a closure bound with `Loader::class` reads that class's private members. `phpx test --matrix ./phpx/testdata/classes/...` passes `closure_bind.phpt`. Go test: `TestClosureBind`.
- [X] `rt.Vendor(fsys)` mounts an embedded vendor tree behind the root and defaults `Include` to `vendor/autoload.php`. `go test -tags phpx ./runner -run Vendor`.
- [ ] The scope check holds: `README.phpx.md` names the OOP baseline as the scope and extensions as out of it, and `phpx/testdata/report.md` carries the extension totals and the biggest blockers of each tested project. `php phpx/scripts/extension-tally.php DIR` regenerates the counts.
- [ ] phpunit runs from its source tree: `cd phpx/testdata/phpunit && composer install --ignore-platform-reqs && phpx run launcher.php --testdox tests/CalcTest.php` runs seven tests and reports a pass, a failure and a skip; `tests/ATest.php` prints `OK (1 test, 1 assertion)`. Open: a skipped test is also counted risky, attributes and doc comments are absent so data providers do not run, `createMock` needs `eval`, and a `phpunit.yml` with a `phpx phpunit` command that globs `*Test.php`. The numbers are in [phpx/TESTING.md](phpx/TESTING.md).
- [X] Destructuring, heredoc, `and`/`or`/`xor`, `for` lists, named arguments, array spread, `print`, `match`, `throw` and `clone` as expressions, `enum` and `use A\{B, C}` parse and run as php does. `phpx test --matrix ./phpx/testdata/syntax/... ./phpx/testdata/classes/... ./phpx/testdata/functions/...` passes all three columns.
- [X] Reflection, the SPL structures and the SPL interfaces work on script classes. `phpx test --matrix ./phpx/testdata/classes/...` passes `reflection_test.php`, `spl_structures_test.php` and `spl_interfaces_test.php`.
- [X] Constructor property promotion declares the property and fills it before the body runs. `phpx test --matrix ./phpx/testdata/classes/...` passes `promotion.phpt` over defaults, private, protected and `readonly` parameters, a parent constructor chain, an inherited promoted constructor, and a body that rewrites the property.

## Upstream

- [ ] A program transform hook in `runner`. `runner/runner_load.go` and `runner/precompiler.go` call `parser.ParseFile` themselves, and an overlay outside the module never sees an included file's AST. Validated by the merged PR and by `migrations/` losing the step the hook replaces.
- [ ] `docker/Dockerfile` reads the `NAME` build argument it already receives. Validated by `atkins build` passing on this checkout without `phpx/docker/Dockerfile`.

## Discovered, not implemented

These came up while settling the five reversals and none is one of them. Each is a decision waiting for an issue; a box lands here with the command that shows the difference.

- A function declared inside a top-level `if` is not defined, and php declares it when the block runs. `php -r "if (!function_exists('f')) { function f() { return 'called'; } } echo f();"` prints `called`; `phpx` parses the declaration and raises `call to undefined function f()`. composer's `autoload_files.php` files wrap helper declarations in this guard, `ralouphie/getallheaders` among them, and the framework report names the wall.
- A second declaration of one class name, and a class named `stdClass`, now raise `Cannot redeclare class A`; `phpx/testdata/classes/` settles it. The message stops short of php's `(previously declared in FILE:LINE)`, because `model.ClassDecl` carries no line. A class declared in two included files is not caught: only one program's declarations are compared.
- `foreach ($rows as [$a, $b])` is a parse error (`expected assignable target in foreach`); php destructures the element. `php -r 'foreach ([[1,2]] as [$a,$b]) echo $a+$b;'` prints `3`. `list()` in a foreach is likely the same gap; check it before fixing.

- `fn($x) => expr` parses and runs (`phpx/testdata/functions/arrow_function_test.php`). Limit: a variable the body names that the enclosing frame lacks is captured as null where php leaves it undefined; the bytecode engine declines the program.
- `<=>` parses and runs (`phpx/testdata/functions/spaceship_test.php`), lowered to a call so operands evaluate once. Limit: the formatter prints the lowered call, and the untagged build has no such function.
- `__TRAIT__` and `__CLASS__` in a trait method, and `get_class()` with no argument, now answer as php does; `phpx/testdata/traits/magic_names.phpt` settles it. `__METHOD__` keeps the trait's name, which php also answers.
- `class_implements()` is unregistered (`class_parents()` and `strval()` are bound). A plain object with no `__toString` now raises php's Error in `echo`, concatenation, `implode`, `sprintf` and `str_replace`, and `Stringable` is added to a class that declares `__toString` (`phpx/testdata/classes/stringable.phpt`); the `(string)` cast (`helperCast` returns no error) still answers the empty string.

- Ten popular packages are linted by `phpx/scripts/package-survey.sh` (list and rules in `phpx/testdata/packages/README.md`). The widest wall is `??`: 99 of the failing files. Run it again after any parser change and compare `survey.md`.
- Bound from the survey into `stdlib/phpx/`: `get_debug_type`, `is_resource`, `is_scalar`, `is_iterable`, `is_countable`, `boolval`, `strval`, `is_nan`, `is_finite`, the `ctype_*` family, `gethostname`, `sys_get_temp_dir`, `json_last_error(_msg)`, `preg_last_error(_msg)`, `restore_error_handler`, `date_default_timezone_get/set`, `strcspn`, `octdec`, `fmod`, `mb_strwidth`, `nl2br`, `mb_check_encoding`, `levenshtein`, `gmdate`, `hrtime`, `uniqid`, `array_product`, `array_replace`, `class_parents`, `interface_exists`. `phpx test --matrix phpx/testdata/functions/...` settles them. Limits: `json_last_error` and `preg_last_error` always answer "no error" because those bindings raise; `gmdate` prints the host zone's name for `e`/`T`/`O`; `is_iterable`/`is_countable` take any array; `class_implements` is not bound because `model.Class.Implements` is lower-cased.
- Flagged, not bound (more than two arguments or a constant family): `trigger_error`, `parse_url`, `setlocale`, `wordwrap`, `mktime`, `checkdate`, `str_getcsv`, `substr_compare`, `extract`, `iterator_to_array`, `array_walk`, `array_walk_recursive`, `settype`, `curl_*`, `stream_*`, `proc_open`, `current`/`next`/`key`.

## Outside the scope

These stay as phpscript decided them, and a box that needs one of them is a box that needs an issue first.

- No extension to the standard library. The snippets record what they wanted; `phpx/testdata/report.md` is where that goes.
- The "Won't build" table in `docs/design.md`: `eval`, `goto`, generators, `curl_*`, PDO, `&` outside `foreach`, and the rest.
- One type per variable name stays a lint convention. The runtime accepts a reassignment and the linter reports it as advice.
